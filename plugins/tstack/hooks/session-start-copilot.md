On GitHub Copilot, load tstack skills by their bare names through the `skill` tool (`solo`, `tdd`, `architect`, not `tstack:solo`). Never dispatch a `task`: tstack does not spawn, and Copilot has no way to reach a Claude session the user opened, so tstack is solo here. Copilot lists only part of a large plugin's skills in its prompt; every tstack skill a workflow names still loads by that name. `.github/copilot-instructions.md` and `~/.copilot/copilot-instructions.md` count as user instructions. Resolve every Claude tool, model, path, and built-in skill a tstack skill names through `references/copilot-tools.md` in the `solo` skill directory. tstack ships no default Copilot models. A skill that names role models takes them from the user's saved tstack model choices; they describe which model suits which work, and dispatch nothing. The plugin hook reads them from the Copilot model sheet, `${COPILOT_HOME:-~/.copilot}/tstack-models.md`, checks them, and adds them to the end of this block. Do not `view` the sheet. It sits outside the workspace, so reading it asks for path access. After `setup-tstack` writes the sheet in this session, use the values it just wrote.

Skills that name role models: `architect`, `how`, `interrogate`, `solo`, `why`.
